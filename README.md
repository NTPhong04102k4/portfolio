# 🚀 Portfolio — Nguyễn Thế Phong

Personal portfolio website built with **pure HTML, CSS & JavaScript**.

## ✨ Features

- 🌙 Dark cyberpunk theme with purple-cyan gradient
- 💎 Glassmorphism design system
- 🎯 Interactive particle network hero background
- ⌨️ Typewriter effect
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎬 Scroll-reveal animations with Intersection Observer
- 🔍 Project filtering by category
- 📬 Contact form with validation
- ⚡ Zero dependencies — pure vanilla code

## 🛠️ Tech Stack

| Layer     | Technology       |
|-----------|-----------------|
| Structure | HTML5            |
| Styling   | CSS3 (Custom Properties, Grid, Flexbox) |
| Logic     | Vanilla JavaScript (ES6+) |
| Fonts     | Google Fonts (Inter, Outfit) |
| Icons     | Font Awesome 6   |
| CI/CD     | GitHub Actions → GitHub Pages |

## 🚀 Deploy

This project auto-deploys to **GitHub Pages** via GitHub Actions.

### Steps:
1. Push code to `main` branch
2. Go to **Settings → Pages** → set Source to **GitHub Actions**
3. The workflow will automatically build and deploy

### Manual:
Simply open `index.html` in a browser — no build step required.
